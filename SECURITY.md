# Security Policy — archived project

Factur-X Engine was discontinued on 24 August 2026. No version is supported or
maintained, including the final frozen release `2.1.0` and the published Docker
images.

This repository does not provide vulnerability monitoring, acknowledgement,
assessment, remediation, disclosure, release deadlines, or security updates.
The former private reporting address is no longer a project support channel.
Do not send production invoice data, credentials, licence keys, or personal data.

Anyone continuing to use the software must independently assess the code,
dependencies, container, deployment, and applicable requirements, and must
maintain a fork or select a maintained alternative. The MIT licence and its
as-is warranty disclaimer continue to apply.
