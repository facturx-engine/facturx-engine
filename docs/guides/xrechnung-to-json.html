Intake

XRechnung to strict JSON

/v1/serialize maps supported UBL Invoice documents into the versioned Intake schema after complete configured validation.

Request

curl -X POST http://localhost:8000/v1/serialize \
  -F file=@xrechnung.xml

Strict scope

The current contract does not support UBL CreditNote and does not silently discard allowances, charges, periods or attachments. Unsupported material groups produce HTTP 422 diagnostics.

A successful response separates execution, validation and mapping status and returns suggested_route: continue_client_checks. It never claims that the invoice is ready to book or pay.

Need only a preview? Use /v1/extract, whose output is explicitly unsuitable for automatic import.

Strict mapping is not automatic accounting acceptance.
