Erreurs de Validation Factur-X

Décrypter les codes d'erreur cryptiques de Chorus Pro, CII, et EN 16931.

BR-CO-10 Critique

Numéro de TVA Acheteur Manquant

La facture tente de déclencher la logique d'autoliquidation ou de TVA intracom, mais l'identifiant fiscal de l'acheteur est introuvable.

"buyer": {
  "name": "Client SAS",
  "vat_number": "FR12345678901" <-- Manquant
}
BR-CO-16 Paiement

Coordonnées Bancaires Manquantes (IBAN)

Vous avez spécifié un moyen de paiement "Virement" (Code 58 ou 30) mais vous n'avez pas fourni les détails du compte bancaire.

"seller": {
  "name": "Ma Société",
  "iban": "FR76..." <-- Requis
}
BR-S-08 TVA

Taux Incorrect pour la Catégorie S

Pour la catégorie de TVA 'S' (Standard), le taux NE DOIT PAS être zéro.

"items": [{
  "vat_category": "S",
  "vat_rate": 20.0 <-- Doit être> 0
}]
