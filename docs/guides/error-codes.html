Common Validation Errors

Decrypting the cryptic error codes from **Chorus Pro**, **CII**, and **EN 16931**.

BR-CO-10 Critical

Buyer VAT Identifier Missing

The invoice attempts to trigger VAT accounting logic but the system cannot identify the Buyer's tax status.

"buyer": {
  "name": "Client SAS",
  "vat_number": "FR12345678901" <-- Missing
}
BR-CO-16 Payment

Payment Account Identifier Missing (IBAN)

You specified a "Credit Transfer" payment means (Code 58 or 30) but did not provide the bank account details.

"seller": {
  "name": "My Company",
  "iban": "FR76..." <-- Required
}
BR-S-08 Tax

VAT Category Rate Mismatch

For VAT Category 'S' (Standard), the rate MUST NOT be zero.

"items": [{
  "vat_category": "S",
  "vat_rate": 20.0 <-- Must be> 0
}]
