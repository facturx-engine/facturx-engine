Inbound workflow

Receive invoices with explicit trust levels

1. Validate

curl -X POST http://localhost:8000/v1/validate \
  -F file=@invoice.xml

Check validation_completeness, layers_executed and layers_skipped. A boolean alone is insufficient evidence.

2. Inspect or map

Use /v1/extract for a best-effort preview. Its result is explicitly unsuitable for automatic import.

Use /v1/serialize for strict schema-v2 mapping. Malformed XML, incomplete validation, missing required values, unsupported material groups and invariant failures return HTTP 422.

3. Apply client controls

Even strict serialization does not perform supplier matching, duplicate detection, purchase-order matching, tax-policy checks or payment approval.

Technical evidence is one input to your wider invoice process.
