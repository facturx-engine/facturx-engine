Strict mapping request

curl -X POST http://localhost:8000/v1/serialize \
  -F file=@invoice.xml

HTTP 422 is an expected workflow response for malformed, invalid, incompletely validated or unsupported documents. Read each diagnostic’s code, source, path and message.

Boundary: a successful mapping still requires supplier matching, duplicate detection, purchase-order matching, tax-policy checks and payment approval.
