Deployment

Runtime architecture

A Python REST boundary with bundled validation tools, packaged as one self-hosted Docker image.

Runtime components

Factur-X Engine exposes a Python REST API and invokes bundled Java tools for selected Schematron and PDF/A checks. It is therefore not a pure-Python or no-Java implementation.

Network boundary

Invoice-processing requests do not require a hosted Factur-X API. Operators may run the container with restricted or disabled networking after pulling the image. Image pulls, builds, updates and surrounding deployment tooling can still require network access.

No certification claim: this is an implementation description, not a security, privacy, GDPR, DORA or regulatory certification.

Deployment security remains the operator’s responsibility.
