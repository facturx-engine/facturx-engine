Generate Factur-X with PHP

The robust way to handle e-invoicing in Symfony, Laravel, or WordPress without complex PDF libraries.

Prerequisites

  • PHP 8.1+
  • guzzlehttp/guzzle client

Full Implementation

post('http://localhost:8000/v1/convert', [
        'multipart' => [
            [
                'name'     => 'pdf',
                'contents' => fopen('input.pdf', 'r'),
                'filename' => 'input.pdf'
            ],
            [
                'name'     => 'metadata',
                'contents' => json_encode([
                    'invoice_number' => 'PHP-999',
                    'seller' => ['name' => 'PHP Solutions'],
                    'totals' => ['net_amount' => 120.50]
                ])
            ]
        ]
    ]);

    file_put_contents('factur-x-final.pdf', $response->getBody());
    echo "Success: File generated.";

} catch (\Exception $e) {
    echo "Error: " . $e->getMessage();
}
?>

Why HTTP vs Library?

PHP libraries for PDF/A-3 (like tcpdf or wrappers around Ghostscript) are notoriously fragile and consume huge amounts of RAM. By offloading this to Factur-X Engine via Docker, your PHP application remains lightweight, fast, and crash-proof.
