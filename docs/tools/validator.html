Validation

Technical invoice validator

POST /v1/validate reports the structural and business-rule layers that actually ran. PDF input may also receive a VeraPDF result when that layer is licensed, available and enabled.

curl -X POST http://localhost:8000/v1/validate \
  -F file=@invoice.xml

Read the evidence

Always inspect validation_completeness, layers_executed, layers_skipped and pdfa_valid. A technical result is not tax advice and does not guarantee recipient acceptance.

Deployment boundary

The processing path can run without sending invoice data to a hosted API. Network isolation and access control remain deployment responsibilities.
