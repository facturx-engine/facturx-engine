API overview

Inbound

  • POST /v1/validate — validation evidence and completeness.
  • POST /v1/extract — heuristic preview, never automatic import.
  • POST /v1/serialize — strict schema-v2 mapping or HTTP 422.

Outbound

  • POST /v1/xml — metadata to supported CII XML.
  • POST /v1/convert — metadata and PDF to a hybrid PDF artifact.
  • POST /v1/merge — existing supported XML and PDF/A-3 to a hybrid PDF artifact.

Operations

  • GET /health — liveness.
  • GET /healthz — readiness and tool availability.
  • GET /license/status — accepted key tier and expiry, without revealing the key.
  • GET /diagnostics and /metrics — only when explicitly enabled and protected.

Interactive reference: runtime OpenAPI documentation is available at /docs; the checked-in specification is available as openapi.json.
