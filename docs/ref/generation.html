Hybrid PDF Generation

How Factur-X Engine creates compliant **PDF/A-3** files with embedded **Cross Industry Invoice (CII)** XML.

PDF/A-3 ISO Standard

Factur-X is a hybrid format. It is a standard PDF (visual representation) that contains an XML file (structured data). To be compliant, it must follow **ISO 19005-3 (PDF/A-3)**.

1

XMP Metadata Injection

The engine injects a specific Factur-X XMP extension schema into the PDF metadata, identifying the file as a compliant invoice and specifying its profile (MINIMUM, BASIC, COMFORT, or EXTENDED).

2

File Attachment (factur-x.xml)

The structured XML is attached as a "Related File" (Relationship: Source). The engine ensures the attachment name is strictly factur-x.xml as required by the standard.

The "Under the Hood" Process

When you call `/v1/convert`, the engine performs a **zero-copy-ready** stream transformation. It parses your PDF, reconciles it with the generated XML, and rebuilds the XMP packet without re-rendering the whole document. This preserves high-quality typography and interactive elements of the original PDF.

# Workflow Detail
- Validate JSON Metadata
- Transform JSON to CII XML (Jinja2)
- Inject ZUGFeRD XMP Extension
- Attach factur-x.xml (AFRelationship)
- Final compliance check
