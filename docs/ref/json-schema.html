Strict serialization schema v2

Schema version 2.0.0 separates successful strict mappings from expected HTTP 422 refusals.

Success

HTTP 200 requires complete configured validation and complete mapping without XML recovery, invented defaults or silently ignored supported material elements. Optional absent source fields remain null.

Refusal

Missing required fields, invalid decimals or dates, unsupported material groups and invariant failures produce stable diagnostics instead of a partial invoice marked as successful.
