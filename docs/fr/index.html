Questions Fréquentes

Pourquoi utiliser un conteneur Docker ?

La conversion PDF/A-3 est complexe. Docker isole les dépendances (évite l'enfer Ghostscript/Java) assurant un environnement "Iso-Prod" stable partout. Évitez les "Ça marche sur ma machine".

Est-ce que ça extrait les données en JSON ?

Oui ! L'Édition Community (/v1/extract) extrait les données de facturation des PDF vers un format JSON standard et non masqué. L'Édition Pro (/v1/serialize) va plus loin en fournissant une Sérialisation Business-Ready : elle normalise les XML complexes CII et UBL en un schéma JSON strict et de haute précision conçu exclusivement pour les intégrations ERP rigides.

Puis-je générer du XML pur sans PDF ?

Absolument. Alors que le endpoint principal /v1/convert incorpore le XML dans vos PDF existants, le moteur expose un endpoint /v1/xml dédié. Passez vos métadonnées JSON, et il retournera directement un XML Cross Industry Invoice (Factur-X) ou XRechnung entièrement conforme.

Puis-je valider des fichiers XML purs ?

Oui ! Bien qu'il gère le PDF/A-3, le moteur expose un endpoint dédié /v1/xml pour valider les fichiers XML bruts contre toutes les règles B2B Schematron (EN 16931, XRechnung) indépendamment de tout conteneur PDF.

Est-ce compatible avec la Réforme 2026 / PDP ?

Oui. Le moteur produit des fichiers strictement conformes à la syntaxe EN 16931 mandatée par le PPF et les candidats PDP. Il supporte tous les profils requis.
