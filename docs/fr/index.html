Fonctionnalités & Intégration

Générez Factur-X PDF/A-3 + XML

Convertissez n'importe quel PDF standard en facture hybride conforme. Le moteur gère la structure complexe du PDF, attache le XML et crée la structure PDF/A-3 conforme à l'archivage légal.

$ docker run -p 8000:8000 facturxengine/facturx-engine

Validez EN 16931 (Schematron)

Conçu pour la conformité Réforme 2026. Le moteur inclut les profils Schematron officiels pour valider les règles métier strictes (totaux, TVA, mentions obligatoires) avant l'envoi au PDP ou Chorus Pro.

Middleware Docker Auto-hébergé

Conçu pour l'intégration ERP et Logiciels de Compta. Déployez-le en microservice dans votre cluster Kubernetes ou sur une VM simple. C'est une boîte noire : envoyez des données brutes, recevez des documents conformes.

4. Sérialisation Business-Ready (JSON)

Arrêtez de parser des arbres XML complexes. L'Édition Pro transforme Factur-X/ZUGFeRD/CII en un objet JSON plat et normalisé. Optimisé pour l'insertion directe en base de données ou l'affichage UI.

5. Diagnostics Avancés (Angles Morts)

Allez au-delà de la validation standard. L'Édition Pro détecte proactivement les "tueurs silencieux" de factures : incohérences SIRET/TVA, totaux négatifs avec mauvais types, et caractères interdits. C'est un audit préventif avant l'envoi aux plateformes.

Questions Fréquentes

Pourquoi utiliser un conteneur Docker ?

La conversion PDF/A-3 est complexe. Docker isole les dépendances (évite l'enfer Ghostscript/Java) assurant un environnement "Iso-Prod" stable partout. Évitez les "Ça marche sur ma machine".

Est-ce que ça génère ou valide ?

Les deux. Vous pouvez l'utiliser pour convertir des PDF ordinaires en Factur-X, OU pour valider séparément des XML/PDFs contre les règles officielles EN 16931.

Licence : Community vs Pro ?

L'édition Community est complète pour la Génération et la Validation. L'édition Pro débloque l'extraction de données non masquées, la redistribution OEM commerciale, et la garantie/support légal.

Est-ce compatible Réforme 2026 / PDP ?

Oui. Le moteur produit des fichiers strictement conformes à la syntaxe EN 16931 mandatée par le PPF et les candidats PDP. Il supporte tous les profils requis.

Quels profils sont supportés ?

Nous supportons tous les profils standards : MINIMUM, BASIC, BASIC WL, EN 16931 (Comfort), et EXTENDED. XRechnung 3.0 est aussi disponible.
