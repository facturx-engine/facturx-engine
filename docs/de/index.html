Häufig gestellte Fragen

Warum einen Docker-Container verwenden?

PDF/A-3 Konvertierung ist komplex. Docker isoliert Abhängigkeiten (vermeidet die Ghostscript/Java-Hölle) und garantiert eine stabile "Iso-Prod" Umgebung überall.

Extrahiert es Daten zu JSON?

Ja! Die Community Edition (/v1/extract) extrahiert die Rechnungsdaten aus PDFs in ein unmaskiertes Standard-JSON-Format. Die Pro Edition (/v1/serialize) geht noch einen Schritt weiter und bietet Business-Ready Serialisierung: Sie normalisiert komplexe CII und UBL XML in ein striktes, hochpräzises JSON-Schema, das exklusiv für starre ERP-Integrationen entwickelt wurde.

Kann ich reines XML ohne PDF generieren?

Absolut. Während der Haupt-Endpoint /v1/convert XML in Ihre vorhandenen PDFs einbettet, bietet die Engine einen dedizierten /v1/xml Endpoint. Übergeben Sie Ihre JSON-Metadaten, und Sie erhalten direkt ein vollständig konformes Cross Industry Invoice (Factur-X) oder XRechnung XML zurück.

Kann ich reine XML-Dateien validieren?

Ja! Obwohl sie PDF/A-3 verarbeitet, bietet die Engine einen dedizierten /v1/xml Endpoint zur Validierung von reinen XML-Dateien gegen alle B2B Schematron-Regeln (EN 16931, XRechnung), unabhängig von PDF-Containern.

Ist es konform mit der E-Rechnungspflicht?

Ja. Die Engine produziert Dateien, die strikt der EN 16931 Syntax entsprechen. Sie unterstützt alle erforderlichen Profile für XRechnung und ZUGFeRD.
