# Showcase: Receive Invoice

This example shows the inbound path used by ERP, middleware, and finance-system integrations.

It answers four questions:
- Is the incoming invoice structurally valid?
- Was PDF/A actually checked?
- What is heuristic in `/v1/extract`?
- What is explicit in `/v1/serialize` for ERP ingestion?

## Prerequisites

Start the API locally:

```bash
docker run -d -p 8000:8000 facturxengine/facturx-engine:latest
```

Use either:
- the file generated by [../send-invoice/README.md](../send-invoice/README.md), or
- any Factur-X, ZUGFeRD, or XRechnung PDF/XML you want to inspect.

Default input used by the script:
- `examples/send-invoice/out/generated-facturx.pdf`

## Run it

From the repository root:

```bash
bash examples/receive-invoice/run.sh
```

The script will:
- call `/v1/validate`
- call `/v1/extract`
- try `/v1/serialize`
- write results to `examples/receive-invoice/out/`

## Outputs to inspect

- `validation.json`
  - `valid`
  - `validation_completeness`
  - `pdfa_valid`
- `extract.json`
  - `invoice_json._meta.limitations`
- `serialize.json` when Pro is available
  - `fallbacks_applied`
  - `xml_recovery_applied`
  - versioned ERP JSON payload

## Manual curl version

```bash
curl -X POST "http://localhost:8000/v1/validate" \
  -F "file=@examples/send-invoice/out/generated-facturx.pdf" \
  -o examples/receive-invoice/out/validation.json

curl -X POST "http://localhost:8000/v1/extract" \
  -F "file=@examples/send-invoice/out/generated-facturx.pdf" \
  -o examples/receive-invoice/out/extract.json

curl -X POST "http://localhost:8000/v1/serialize" \
  -F "file=@examples/send-invoice/out/generated-facturx.pdf" \
  -o examples/receive-invoice/out/serialize.json
```

## Interpretation rules

- `validation_completeness = partial` means some applicable layers did not run.
- `pdfa_valid = null` means PDF/A was not checked or did not apply.
- `/v1/extract` is heuristic best-effort extraction.
- `/v1/serialize` is the ERP-oriented contract, with transparent fallbacks.

For the full semantics, read [../../TRUST_MODEL.md](../../TRUST_MODEL.md).
